«Генетический алгоритм как инструмент инженера: практический кейс раскроя полотен»

Кратко: репозиторий содержит Jupyter/Colab-ноутбук с реализацией генетического алгоритма (ГА) для задачи раскроя полотен — от подготовки входных данных (дробление заказов в полосы) до визуализации и отбора вариантов для передачи в производство.


Краткое описание идеи

Дана производственная задача: набор заказов (прямоугольных изделий), нужно разместить их по полотнам фиксированной ширины так, чтобы минимизировать обрезь (отходы) и одновременно соблюдать технологические ограничения.
Решение: выразить один вариант раскладки как вектор целых чисел (каждое число — индекс полотна для соответствующей полосы) и применять ГА: оценка (function_error) → отбор → скрещивание → мутация → повтор.

Параметры, которые стоит править

n — размер популяции.

nsurv — элита; разумно 20–60% популяции.

mut и eph_change_mut — стратегия снижения мутаций (в ноутбуке пример со ступенями). Рекомендация: рассмотреть адаптивное снижение на основании стагнации.

lp — число полотен, по которым суммируется ошибка (параметр стратегии частичной оценки). Нужен подбор под кейс.
